# ADR-003 — Local-first Architecture for Prompt Hub V1
- Status: Architecture approved by product owner; implementation verification pending.
- Date: 2026-10-18.
- Decision: Responsive static PWA, IndexedDB, GitHub Pages, user-managed JSON backup/restore.
- Excluded from V1: authentication, cloud database, cross-device sync, Android Share Target.
- Deferred to V1.1: Android Share Target.

## Consequences and risks
- Data is scoped to this browser profile and origin; migration requires export/import.
- Browser data can be cleared; backups are essential and are plaintext JSON.
- GitHub Pages is public hosting; never publish personal records, backups, or secrets in source.
- Persistent storage requests are browser-controlled and not guaranteed.

## Acceptance criteria
1. Prompt CRUD, favorites, search, category filter, tags persist across reloads.
2. Template variables replace correctly and generated text can be copied/saved.
3. Skill CRUD/search/copy retains Markdown.
4. Backup exports all stores and schema metadata.
5. Restore validates schema and IDs before writes.
6. Merge and replace work transactionally across stores.
7. Malformed backup does not change existing data.
8. Restore works in a separate browser profile/device.
9. Responsive UI works on Android and desktop.
10. PWA shell deploys over HTTPS and caches after first visit.
